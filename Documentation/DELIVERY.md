## 0.4.1 补查修复

复现并修复拼图拖动中切换竖屏、再返回横屏释放时意外交换碎片的问题。描字、装裱、拼图、清灰和清沙统一在失焦、暂停、打开菜单及进入竖屏时取消未完成的手势，已完成进度仍按原规则保存。真实鼠标操作已验证竖屏取消、菜单取消，以及中断后重新拖动正常交换。

补查还发现一次引擎报告成功但资源归档不完整的导出，浏览器日志提示缺少 GlobalGameManagers，实际呈空白画面。清理构建缓存后重新导出恢复正常；构建脚本现在会拦截归档读取失败，即使引擎返回成功也不会继续作为有效导出。浏览器检查同时识别这类初始化失败日志。

## 打开与交付

完整游玩视频位于项目旁的 `山海神隐录_完整游玩Demo_0.4.1.mp4`，按玄曜主线、灵曦主线、调和结局回放的顺序编排，带游戏配乐与音效。另附 `山海神隐录_Demo播放_0.4.1.html` 本地章节播放器及 `山海神隐录_Demo章节_0.4.1.txt` 时间表。视频含剧情剧透，无人物语音。

画面录自正式 H5 的实际鼠标操作。两条主线从新旅程开始，第三结局使用游戏内章节快照；没有注入存档或剧情状态。灵曦结局对白之后录制浏览器异常，收卷和图鉴通过重新实际游玩补录，最终由四段素材拼接，无加速。两条主线共覆盖 34 个幕节点，视频不展示另两个可选分支和全部选择排列；核心检查覆盖全部 36 节点与 24 条完整路径。

本机双击项目中的 **开始H5游戏.cmd** 或 **开始试玩.cmd**，打开 <http://127.0.0.1:8766/>。启动器需要本机已安装的 Python 3，游玩时保留服务窗口。更新后关闭旧页面再打开，必要时 Ctrl+F5；不必清除站点数据。

交付包位于项目旁：

- `山海神隐录_H5游戏.zip`：完整解压后双击“开始H5游戏.cmd”。
- `山海神隐录_工程与试玩.zip`：团结引擎工程、源码、生成美术、文档和实际截图；不包含 Library 等缓存与导出目录。

本地正式构建在 `Builds/H5`；早期 `Preview/` 是历史 JavaScript 原型，未同步当前调查玩法，不作为本版验收入口。浏览器存档按站点隔离，清理站点数据会删除存档。

旧存档保留剧情和奖励；已完成调查不会强制重做。要体验新调查，可从第一章章节快照回放或开始新旅程。0.2.0 已使用扇子的丹穴存档视为三处炉口已清开。所有节点奖励按原规则每份旅程只结算一次。
