# 交付与验证记录

日期：2026-10-18。适配、备份与推理更新版 **0.6.0**，本地横屏 H5。

## 0.6.0 补充制作

- 网页与引擎统一按 CSS 画布尺寸选择布局，覆盖高 DPI 与模拟手机安全区域；打开阅读、设置或确认面板时隐藏网页全屏按钮。
- 扩大滑条、确认与翻页等点击区域。阅读字号作用于对白、回看、手记、图鉴正文和两处推理，长文本按实际高度排版并支持滚动。
- 七个存档位、收藏、章节快照与设置可导出、导入。导入先检查校验和及嵌套内容，再确认覆盖；保留导入前快照。普通保存保留上一份有效记录，损坏时尝试恢复并提示。存储拒绝写入时清除本次部分写入，再恢复原记录。
- 两处推理结论顺序随机并随进度保存；双卷增加两份人物见闻证据，错误或无关证据不能完成。三级提示由玩家主动展开。
- 冰碑融开、河碑显露、叶门转动与桥阶修复增加过渡。桥阶尺寸、角度、色调有细微变化，人物随场景调整色温。减少动态效果设置仍生效。
- 满收藏、七个通关存档和恢复副本的校验样本约 438 KB；另测文件损坏、无效章节、过大文件、保存失败、部分写入失败及回滚。参考 [Unity PlayerPrefs 容量说明](https://docs.unity3d.com/cn/2022.3/ScriptReference/PlayerPrefs.html)，可下载的备份文件应另外保管。

## 保留的 0.5.0 更新

- 三个结局取消重复人物立绘，完整 CG 留出画面主体；收卷后仍可进入图鉴、行卷和章节回放。
- 手机横屏重排标题页和底栏，放大对白与主要按钮；标准、较大、大字三档可跨刷新保存。
- 不周残阶加入远近比例、雾色和接触阴影；桑叶门按场景光色融合；人物裁边柔化、书写笔画增加粗细变化。
- 装裱需观察金乌、转正拓片、选对日轮印；记忆拼图随机开局，复原后选择朱笔与青卷两处证据再推理；双卷配对后结合相柳与罔象经历得出结论。错误答案可修正，奖励只结算一次。
- 50 幅所需美术按场景独立加载，按约 72 MiB 目标回收不再显示的纹理并提供失败重试；不再把全套美术放入初始 data 包。资源从 Assets/Art 自动导出，JPEG 用于不透明场景，PNG 保留透明素材，并未使用 GPU 压缩纹理。
- 111 段对白改为显式表情配置；新增六种原创合成反馈音效。Windows 自带本地启动器，先核对全部构建与场景文件的 SHA-256，避免遗漏文件或打开旧服务。

发布包需经过十二组真实浏览器检查，测试结果绑定实际构建清单的 SHA-256，不能用其他版本的通过记录打包。`Tools/verify_export.ps1` 可用 `-BuildDirectory` 和 `-Url` 指定待验导出。

## 保留的 0.4.1 修复

Release 发布复查发现并修复启动器误复用旧服务的问题：此前只检查页面标题，旧版服务未关闭时，新包可能仍打开旧画面。启动器现在核对页面与完整 H5 构建文件；只有内容一致才复用原地址，否则提示先关闭旧服务。完整性检查也提前到复用服务之前。四个实际 HTTP 回归用例通过。该轮修正只影响启动工具；0.5.0 在此基础上扩展为完整清单校验。

复现并修复拼图拖动中切换竖屏、再返回横屏释放时意外交换碎片的问题。描字、装裱、拼图、清灰和清沙统一在失焦、暂停、打开菜单及进入竖屏时取消未完成的手势，已完成进度仍按原规则保存。真实鼠标操作已验证竖屏取消、菜单取消，以及中断后重新拖动正常交换。

补查还发现一次引擎报告成功但资源归档不完整的导出，浏览器日志提示缺少 GlobalGameManagers，实际呈空白画面。清理构建缓存后重新导出恢复正常；构建脚本现在会拦截归档读取失败，即使引擎返回成功也不会继续作为有效导出。浏览器检查同时识别这类初始化失败日志。

## 验证范围

本次交付为本地 H5。真实 iOS Safari、Android 浏览器及微信/抖音内置浏览器尚未做真机验收；模拟触摸检查不替代真机测试。微信和抖音小游戏 SDK、平台登录、广告、支付、云存档及商店发布尚未接入。完整导出约 82.5 MiB；美术按当前场景加载，标题页首次传输约 21.4 MiB。加载耗时取决于设备与网络，本机浏览器测量写入 verification.json 的 quality 字段，不代表手机真机网络表现。
